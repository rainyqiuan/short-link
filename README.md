# short-link · 高并发短链平台

把长链接转换成短链，并在高并发访问下完成一跳跳转。目标是做成一个能讲清「缓存 / 限流 / 异步 / 压测」的完整后端项目。

> 当前状态：**W1 · 环境搭建中**（骨架已就绪，尚未开始写业务代码）

## 技术栈（规划）

| 层 | 选型 |
|---|---|
| 语言 / 框架 | Java 17 · Spring Boot 3.5 |
| 持久层 | MyBatis-Plus · MySQL 8 |
| 缓存 | Redis 7（缓存 · 布隆过滤器 · 分布式发号 · Lua 限流） |
| 接口文档 | Knife4j（OpenAPI 3） |
| 运行环境 | 中间件跑 Docker Compose，应用跑本机 |
| 压测 | JMeter |
